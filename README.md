
# Black Crusade: Chaos Hub

**Интерактивная система для игры в Black Crusade (Warhammer 40k).**

## Возможности

- 📜 Справочник по механикам, демонам, бою
- ⚔️ Боевой трекер с инициативой, уроном, статусами
- 👤 Генератор и ведение чарников демонов
- 🔥 Реальное время через Firebase Firestore

## Технологии

- HTML5 / CSS3 (тёмная тема WH40k)
- Vanilla JavaScript (ES Modules)
- Firebase Firestore (реалтайм база данных)
- GitHub Pages (хостинг)
