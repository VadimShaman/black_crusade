# Black Crusade: Chaos Hub

**Интерактивная система для игры в Black Crusade (Warhammer 40k).**
Боевой трекер, справочник механик, генератор демонов — всё в одном месте.

🌐 **Сайт:** https://vadimshaman.github.io/black_crusade/

---

## 📌 Возможности

- 📜 **Полный гайд по Black Crusade** — базовые механики, бой, стрельба, рукопашка, статусы, демоны, командование.
- ⚔️ **Боевой трекер в реальном времени** — инициатива, урон, статусы, счётчик убийств, лог боя.
- 🎲 **Кубы** — d4, d6, d8, d10, d12, d20, d100, а также произвольные выражения (например, `3d6+2`).
- 👥 **Участники** — добавление игроков, союзников, врагов, NPC с шаблонами.
- 🎯 **Калькулятор атаки** — ручной ввод оружия, порога попадания, кубов урона, модификаторов.
- 📝 **Заметки GM** — сохраняются в браузере (localStorage).
- 📥 **Экспорт/импорт лога** — сохраняй историю боя в JSON и загружай обратно.
- 🔥 **Реальное время** — все изменения синхронизируются через Firebase Firestore.

---

## 🛠️ Технологии

- **HTML5 / CSS3** — тёмная тема в стиле WH40k, адаптивная вёрстка.
- **Vanilla JavaScript (ES Modules)** — вся логика без фреймворков.
- **Firebase Firestore** — облачная база данных для синхронизации боёв.
- **GitHub Pages** — бесплатный хостинг.
