🎲 1. Базовый Тест & Тайминги

Предел = Характеристика + Бонус Навыка + Модификаторы[cite: 4]

Бросок: 1d100 ≤ Предел ➔ Успех[cite: 4]

  • Уровни Успеха (DoS): +1 за каждые полные 10 единиц ниже предела[cite: 4].
  • Криты: Натуральные 1-5 — Критический Успех. 96-100 — Критический Провал[cite: 4].
  • Раунд: 5 секунд. Персонаж имеет 2 ОД и 1 Реакцию в раунд[cite: 2].

🛡️ 2. Логика Защиты & Поглощения

  • Уклонение (Реакция): Тест `Dodge(A)+0`[cite: 2, 4]. Успех аннулирует попадание[cite: 2, 4]. Позволяет сделать Отскок на расстояние до `SPD` метров[cite: 2, 4].
  • Парирование (Реакция): Тест `Parry(WS)+0` только против ближнего боя[cite: 2, 4].
  • Поглощение урона: `T.b` (Бонус Стойкости) + `АР` (Броня)[cite: 2, 4]. Финальный урон = Урон − Поглощение[cite: 2, 4].
  • Критический Урон: Если куб выдает 10 (или 5 для d5)[cite: 2]. Бросается 1d5 по таблице Критических повреждений при отрицательных ранах[cite: 2, 4].

🔥 Особенности Богов Хаоса

  • Кхорн: Нет магии[cite: 3]. Вместо феноменов при провале WP — Ярость (+5 WS, +5 S)[cite: 3]. Способность «Ярость Кхорна» (Frenzy без теста + 1d5 хитпоинтов)[cite: 3].
  • Тзинч: Стартовый PR 2[cite: 3]. С силами работает через систему Гримуара знаний (силы нужно искать и записывать тестом WP 40)[cite: 3].

  • Ранг 2 (Возвышенный): Inf 16-30, Cor 11-25. Получает `+1 PR`, `+5 к характеристике`[cite: 3].
  • Ранг 3 (Герольд): Inf 31-50, Cor 26-40. Получает Локус контроля (ауру)[cite: 3].
  • Ранг 4 (Высший): Inf 51-80, `+2 PR`, три характеристики `+10`, Дар Бога[cite: 3].

⚙️ Системные правила: Статусы, Борьба, Орды и Страх

☣️ Таблица Боевых Статусов

  • Усталость: −10 ко всем тестам за каждый уровень[cite: 2, 4]. Накопление `T.b + WP.b` уровней вырубает персонажа[cite: 4].
  • Оглушён: Не может совершать действия, к атакам по нему дается бонус +20[cite: 2, 4].
  • Горение: Получает 1d10 E(Fl) урона каждый ход[cite: 4]. Требуется тест `WP+0`, чтобы не пропустить ход от боли[cite: 2, 4].
  • Сбит с ног: Персонаж лежит[cite: 2, 4]. Штраф −20 к `WS/Dodge`[cite: 2, 4], бонус +20 к скрытности[cite: 4], скорость деленная на 2[cite: 2, 4].

🤼 Механика Борьбы и Захватов[cite: 4]

Вход в борьбу: Успешная рукопашная атака ➔ встречный тест `Athletics(S) vs Athletics(S)`[cite: 2, 4].

  • Заломить (Атакующий): Встречный тест `Athletics(S)`. Успех наносит `1d5 + S.b` ударного урона[cite: 2, 4].
  • Вырваться (Цель): Полное действие, успешный тест `Acrobatics(A) vs Athletics(S)` атакующего[cite: 2, 4].
  • По обоим борющимся персонажам сторонние стрелки бьют с бонусом +20[cite: 4].

👥 Механика Орд (Hordes)[cite: 4]

Орда имеет параметр Магнитуды вместо ран[cite: 4].

  • Каждое стандартное попадание снижает Магнитуду ровно на 1 (урон оружия не важен)[cite: 4].
  • Оружие с чертой `Blast(X)` наносит дополнительные `+X` повреждений Магнитуде. Огненное (`Flame`) дает `+1`[cite: 4].
  • Атаки орды невозможно избежать (`Dodge/Parry` запрещены)[cite: 4].
  • При падении Магнитуды ниже 25% орда мгновенно распадается[cite: 4].
